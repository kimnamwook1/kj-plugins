# ADR-00001 · 원본 미보존 (no-source-retention)

## 3중 게이트

- 불가역: 폐기한 원본은 재처리 불가 — 모델 교체 시 과거 노트 재요약이 영구히 막힌다
- 의아: 보존하면 재요약·품질 개선이 공짜인데 왜 버리는가 — 후임자가 반드시 되물을 결정
- 트레이드오프: 재처리 능력 vs 저작권 리스크·저장 비용 — 양쪽 다 실질 비용

## Context

- Whisper 경로는 음성 파일을 R2에 내려받아 전사한다 — 파이프라인상 원본이 인프라에 머무는 유일 구간
- 저작권법 적용 판정이 검토중 (COMPLIANCE §Legal Sources) — 원본 보유량이 곧 리스크 노출량
- 20분 영상 음성 ~20MB — 월 1만 편이면 저장 비용이 요약 원가와 같은 자릿수

## Decision

- 영상·음성 원본과 자막 원문을 **요약 병합 직후 폐기**한다 — R2·D1 어디에도 남기지 않는다
- 파생물(요약 노트·타임스탬프)만 보존

## Consequences

- (+) 저작권 리스크 상한 = 처리 중 순간 보유량 — 침해 주장 시 삭제 증명이 방어선
- (+) 저장 비용 0 — 단위 경제가 요약 원가만으로 닫힌다 (GTM §가격)
- (−) 모델 개선 시 과거 노트 일괄 재요약 불가 — 사용자가 URL 재제출해야 함
- (−) 실패 잡 디버깅 시 원본 재현 불가 — 실패 사유 문자열을 노트 status에 남기는 것으로 보완
- 집행: 규칙화는 POL이 아닌 파이프라인 코드 + RUNBOOK §원본 폐기 점검 (주 1회 R2 audio/ 0건 확인)

## Revisit trigger

- 저작권법 판정이 "적용 아님"으로 확정되고 재요약 수요가 실측되면 재심 — 그 전 재론 금지
