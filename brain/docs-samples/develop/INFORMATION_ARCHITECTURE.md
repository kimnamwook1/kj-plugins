# INFORMATION_ARCHITECTURE (정보 구조)

## 화면 구조 — 2화면

- 라이브러리: URL 입력 + 노트 카드 목록 (상태별 필터)
- 노트 뷰: 타임스탬프 요약 본문 + 내보내기 버튼

## URL 경로

| 경로 | 화면 | 비고 |
|---|---|---|
| `/` | 라이브러리 | 로그인 후 기본 진입점 |
| `/notes/:id` | 노트 뷰 | 공유 불가 — 소유자만 (THREAT_MODEL §위협) |
| `/settings` | 플랜·내보내기 설정 | Stripe 포털 링크 포함 |

## 콘텐츠 계층

- 사용자 → 노트(영상 1개당 1개) → 요약 블록(청크당 1개, 타임스탬프 앵커)
- 폴더·태그 없음 — 정렬은 생성일 역순, 탐색은 제목 검색 1개 (MVP 경계)

## 내보내기 구조 (PRD R2)

- 파일명: `<video-title-kebab>.md` — Obsidian 파일명 금지문자 치환
- frontmatter: `source_url` · `created` 2키
- 본문: `## [MM:SS]` 헤딩 + 요약 bullet — 타임스탬프는 유튜브 딥링크

## 명명 규칙

- 도메인 명칭은 PRD §용어가 정본 — 화면·코드·문서 전부 "노트"·"청크"로 통일
- 화면 이름은 이 문서가 정본 — "라이브러리"·"노트 뷰" 외 별칭 금지
