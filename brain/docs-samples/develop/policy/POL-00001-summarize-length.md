# POL-00001 · 요약 길이 상한 (summarize-length)

## 규칙

- 청크(10분)당 요약 300자 이하
- 노트 총량 3,000자 이하 — 초과분은 뒤 청크부터 압축 재요약
- 요약 블록당 타임스탬프 1개 필수 — 타임스탬프 없는 블록 생성 금지
- 상한 값의 코드 하드코딩 금지 — 이 문서가 정본, 코드는 config로 읽는다 (CODE_CONVENTION §금지)

## 근거

- 토큰 비용 상한: 출력 토큰이 편당 원가의 40% — 상한 없으면 GTM §가격 단위 경제 붕괴
- 가독성: 3,000자 초과 노트는 열람 완료율 급락 (베타 관찰, M1)
- 타임스탬프 강제: 딥링크가 제품 핵심 가치 (PRD R1) — 요약만 있으면 경쟁 서비스와 무차별

## 적용 범위

- summarize 기능 전 경로 (자막·Whisper 공통) — `../feature/FEAT-00001-summarize.md` §TDC가 집행 지점
