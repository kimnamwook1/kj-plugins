  - 🔴 **"Duplicate-file bug" named a symptom and missed the condition, which is the part that bites.** `create` is not broken — **without the `overwrite` flag it silently forks a name collision into `X 1.md`**, so the write appears to succeed and lands where nothing reads it. The write discipline itself is unchanged, compare-and-swap rationale intact.
  - **The official reference does not carry this.** `obsidian.md/help/cli` documents `overwrite` as "Overwrite if file exists" and stops; the collision behavior is undocumented, so reading the docs would not have surfaced it.
